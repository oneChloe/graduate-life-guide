# 毕业五年人生通关指南

写给即将毕业，以及离开校园零到五年的年轻人。

它不是一份标准答案，也不是把人生做成升级打怪的待办清单。它更像一张由过来人共同补完的地图：当你站在找工作、选城市、跳槽、转行、裁员、租房、关系和家庭这些路口时，可以先看看别人走过什么弯路、付出过什么代价，再决定自己的下一步。

在线体验：<https://graduate-five-year-guide.blitezero.chatgpt.site>

## 现在有什么

- 4 个职业阶段存档
- 5 类当前困境
- 16 条主线关卡
- 10 条生活支线
- 11 场突发 Boss 战
- 37 篇可展开的过来人手册
- 关卡搜索与路线推荐

每个关卡都会尽量回答：

1. 为什么很多人会卡在这里？
2. 常见的几条路线分别适合谁？
3. 每条路线需要付出什么？
4. 过来人见过哪些坑？
5. 离开这一关以前，可以先完成什么？

## 内容原则

这个项目受到[《上海交通大学学生生存手册》](https://github.com/SurviveSJTU/SurviveSJTUManual)和[《高性价比人生指南》](https://github.com/eternity4719/HowToLiveBetter)的启发，但不复制它们的正文。

我们希望保留两种很珍贵的东西：

- 过来人愿意把自己的背景、偏见、弯路和反思讲清楚。
- 涉及政策、健康、法律和金钱时，事实与个人经验必须分开。

这里不会把某一种人生包装成正确答案。每篇内容都应该写明适用条件、现实代价和可能的退出方式。

## 项目结构

```text
dist/
├── index.html          页面结构
├── styles.css         视觉样式
├── app.js             交互与路线生成
└── guide-content.js   全部关卡内容

docs/
└── 投稿模板.md         过来人经验投稿格式
```

这是一个不依赖后端的静态网页。本地查看：

```bash
python3 -m http.server 4173 --directory dist
```

然后访问 `http://127.0.0.1:4173/`。

## 怎样参与

如果你已经毕业一段时间，欢迎提交自己真正走过的一关。我们尤其需要：

- 不同城市、行业和家庭背景的毕业生经历
- 看起来不光鲜，但对后来很有帮助的选择
- 当时为什么会那么选，以及后来如何重新理解
- 能帮助后来者判断的具体问题和检查清单

投稿前请阅读[投稿模板](./docs/投稿模板.md)。涉及他人、公司或用户的信息必须匿名；涉及劳动、社保、医疗、法律和金融规则时，请提供当前可核验的官方来源。

## 版本状态

当前是内容原型。部分章节仍然是编辑部式的过来人叙事，后续会逐步加入署名或匿名投稿者的背景标签，例如行业、城市、毕业年限和路线结果，让读者更容易判断一段经验是否适合自己。

# 资料来源与核验记录

这份指南把内容分成两类：

1. **过来人经验与决策框架**：帮助读者提出问题，不声称是普遍结论。
2. **制度与公共信息**：优先链接政府部门、法律原文和全国性公共服务平台，并记录最近核验日期。

网页中标注“官方资料核验于某日”，只代表该链接和页面在当日完成过人工核对，不代表规则从此不会变化。涉及具体权益、办理条件和争议处理时，仍应根据所在地、合同文本和当前日期重新确认。

## 维护规则

- 优先使用法律原文、政府部门和公共服务平台，不用营销文章替代制度来源。
- 每个链接要写明它支持哪一部分内容，不能用一个“权威链接”给整篇经验背书。
- 地方政策必须标注地区；有时间效力的页面必须标注查询日期。
- 来源失效或规则更新时，先修正文，再更新核验日期。
- 无法确认的内容保留为个人经验，并明确提示读者重新核验。
